Repositorio del proyecto 1 para el curso de Sistemas Distribuidos
# Sistema de Reservas de Hotel

## Instrucciones para ejecutar el proyecto

### Requisitos previos

Antes de ejecutar el proyecto, se debe tener instalado:

- Node.js 18 o superior. Se recomienda Node.js 24.
- npm, incluido con la instalación de Node.js.
- Un navegador web actualizado.
- Conexión a internet para consultar el servicio JSON-RPC de Ethereum y el servicio web del clima.

Las versiones instaladas pueden comprobarse con los siguientes comandos:

```bash
node -v
npm -v
```

### 1. Abrir la carpeta del proyecto

Descomprima el archivo del proyecto y abra una terminal dentro de la carpeta principal, donde se encuentran los archivos `app.js` y `package.json`.

### 2. Instalar las dependencias

El proyecto se entrega sin la carpeta `node_modules`. Para descargar las dependencias y generar esta carpeta, ejecute:

```bash
npm install
```

### 3. Iniciar el programa

Desde la carpeta principal del proyecto, ejecute:

```bash
npm start
```

### 4. Detener el programa

Para finalizar la ejecución, regrese a la terminal y presione:

```text
Control + C
```
